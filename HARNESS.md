## Context

For information about architecture, see _wiki\architecture.md

### Conventions

- **Naming**: camelCase for variables and functions; PascalCase for React components and TypeScript types/interfaces
- **File structure**: `src/` root for all source; `src/lib/` for reusable pure utilities; components co-located near use
- **Error handling**: TypeScript types as primary guard; throw on unexpected/impossible state; no `console.*` calls in production code
- **Documentation**: Literate preambles on every file — why it exists, key design decisions, what it deliberately does NOT do; inline comments explain WHY, not WHAT
